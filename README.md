# 📚 Library Management System

A console-based Library Management System built with Python.

## Features

- Add a new book
- View all books
- Search for a book
- Remove a book
- Check book availability

## Technologies Used

- Python 3
- Git
- GitHub
- VS Code

## Concepts Practiced

- Functions
- Loops
- Conditionals
- Lists
- Dictionaries
- User Input
- Program Flow

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Skinnybaba/library-management-system.git
```

2. Navigate into the project

```bash
cd library-management-system
```

3. Run

```bash
python3 main.py
```
